🛒 E-Commerce Sales and Customer Analytics

Project Overview
This project focuses on analyzing E-Commerce sales data to understand sales performance, customer purchasing behavior, product trends, and business performance.

The project follows an end-to-end data analytics approach using SQL, Python, Microsoft Excel, and Power BI.

Project Objectives
- Analyze overall sales and revenue performance.
- Identify customer purchasing patterns.
- Understand product-wise sales performance.
- Analyze city-wise revenue distribution.
- Track order trends and business performance.
- Generate meaningful insights to support business decisions.

Tools & Technologies

| Tool | Purpose |
| MySQL | Data storage and SQL analysis |
| Python | Data cleaning and analysis |
| Jupyter Notebook | Python development |
| Microsoft Excel | Data analysis and dashboards |
| Power BI | Interactive dashboards and visualization |

Project Files
- ecommerce_analysis.sql – SQL queries and business analysis.
- ecommerce_analysis.ipynb – Python data analysis.
